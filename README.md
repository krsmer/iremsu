# İremsu'nun Doğum Günü

İremsu için hazırlanmış tek sayfalık doğum günü sitesi.

- Açılışta konfeti ve yazılarak gelen mesaj, salıncakta sallanan çocukluk fotoğrafı
- "İyi ki doğdun" melodisini çalan buton
- Dokunarak ya da parmakla üfleyerek söndürülen mumlu pasta
- Swiper ile üst üste duran, sonsuz kaydırılan fotoğraf destesi
- Çevirdikçe gizli özellikleri ortaya çıkaran çark
- Parmakla kazınarak açılan mektup

Çalıştırmak için `index.html` dosyasını tarayıcıda açman yeterli.
